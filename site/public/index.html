Memory is the model's.
The directive is yours.

A model's memory is passive and model-specific. It drifts, it resets, it belongs to whichever system you happened to be talking to. A directive is the active opposite — a model-agnostic instrument you author on purpose and keep.

Stele treats it like source. Declare each project's domain, its compliance tier, the postures that govern how hard to audit, and the lines that must never be crossed. Anchor resolves the active project and compiles the rest into context the model reads first — so the same intent holds even when you switch models entirely.
